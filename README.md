# Egg Catcher Game in Python

A simple 2D Egg Catcher game built using Python's built-in `Tkinter` GUI library. In this game, eggs fall from the top of the screen at random positions, and the player has to catch them using a basket at the bottom.

---

## 📌 Project Overview
This project was created as a beginner Python project to learn basic GUI concepts, event handling, and canvas animation. It does not require any external third-party libraries.

---

## 🎮 How to Play
* Use the **Left Arrow Key (`←`)** to move the basket to the left.
* Use the **Right Arrow Key (`→`)** to move the basket to the right.
* Catch the falling eggs to gain **10 points** per egg.
* You have a total of **3 lives**.
* Missing an egg costs **1 life**.
* The game ends when you lose all 3 lives.

---

## ✨ Features
* **Simple GUI:** Built using `tkinter.Canvas` with custom shapes.
* **Score & Lives Tracker:** Real-time updates for user score and remaining lives.
* **Increasing Difficulty:** Egg falling speed gradually increases as score increases.
* **No Dependencies:** Runs out of the box with standard Python installations.

---

## 🛠️ Requirements & Tech Stack
* **Language:** Python 3.x
* **GUI Framework:** Tkinter (Included with standard Python)
